Person B — Auth system end-to-end
Auth blocks everything user-related. Get it done early.

User registration + login with hashed/salted passwords (bcrypt)
JWT tokens, refresh logic, protected route guards in NestJS
Basic user profile endpoint (GET /users/:id, PUT /users/me)
Avatar upload with default fallback
OAuth 2.0 with 42 intra (most natural for your school) or Google
Frontend: login page, register page, protected route wrapper in Next.js
